# Learn_React 19:
This repository is for learning the React.js

# Vision:

Welcome to the **Learning React** repository!  
This repository is created for **beginners** who want to learn **React.js** step by step in a simple, clear, and practical way.

It focuses on building a strong foundation by explaining core concepts with easy examples and hands-on practice.

---

##  About This Repository

This project helps beginners understand React from scratch.  
It covers fundamental concepts and follows clean coding practices so learners can easily read, understand, and modify the code.

---

## What You Will Learn:

By using this repository, you will learn:

- What React is and why it is used
- How to create and run a React application
- JSX syntax and usage
- Functional Components
- Props and State
- Event handling in React
- Conditional rendering
- Rendering lists and using keys
- Basic React Hooks (`useState`, `useEffect`)
- Project structure and best practices

---

## 🛠 Prerequisites

Before starting, make sure you have basic knowledge of:

- HTML
- CSS
- JavaScript (ES6 basics)

You should also have the following installed:

- Node.js (LTS version recommended)
- npm or yarn
- A code editor (VS Code recommended)

---

## ⚙️ Getting Started

Follow these steps to run the project locally:

1 Create a directory for project:
```
mkdir learning-react 
```

2️ Navigate to the Project Folder
```
cd learning-react
```

3️ Install Dependencies
```
npm init

npm install
```

4️ Start the Development Server
```
npm start
```
The application will run on:
👉 http://localhost:3000
