# what is react?

- react is a library not a framework, as it is all about building user interfaces (web and mobile interfaces).
- it also focus on doing one speacific thing, whereas the framework tries to handle everything
  by itself.
- React does not tries to handle routing or managing complete app logics, this can be resolve by react because React
  has a massive ecosystem of other libraries.
- Plugins are provided for the right tools when necessary.

## why to learn React?
#### Technical Points:

- it has a component based architecture.
- This makes the user interface less complex by breaking the UI into small reusable pieces (Like Header, navbar, main section, footer, Asidebar)
- React is declarative (that means describe what you want in UI to look like and react take care of it) by building and updating the actual UI.
- React can be integrated into any of your applications.
- React can be integrated anywhere in your project for a portion, a complete page or an entire application.
- Using React Native you can build mobile apps.

### General Points:

-it is the most popular library for building user interfaces and has a vast ecosystem and developer's
  community to keep the system more up to date.
- React is been used by most of the tech companies Like meta, facebook, etc.
- Ai tools like claude, Cursor, ChatGPT are excellent at generating react code and provide support tools.
- In an open-source ecosystem this is the skill you most have as it is a must have skill requirement in the job market.
